# NEON (PULSON)
2026 AI+X 해커톤

## 목적
입원 환자가 병상에서 궁금한 점을 물어보면 AI가 대신 응대하고, 판단이 필요한 질문은 간호사가 확인한 뒤 답하게 하는 "AI 상주보호자"입니다. 간호사의 반복 응대를 줄이면서, 의료 판단은 AI가 하지 않고 간호사가 승인하도록 했습니다.

| 상황 | 처리 |
|---|---|
| 일정·검사 준비 같은 단순 질문 | AI가 환자 데이터와 병동 지식을 근거로 바로 답변 |
| 걱정·미열·약 관련 질문 | AI가 간호사용 답변 초안을 만들고, 간호사가 승인·수정해서 발송 |
| 증상 악화 | 중증도를 높여 간호사에게 방문 권고 |
| 긴급 증상 | LLM 없이 키워드 규칙으로 즉시 경보 |

## 모델
`gpt-4o-mini` (temperature 0.2) 하나를 역할별 프롬프트로 나눠 씁니다.

1. **긴급 규칙** (`agent/emergency.py`): 키워드가 걸리면 바로 긴급 처리합니다.
2. **분류** (`agent/prompt.py`): 카테고리(즉답 / 간호사 확인), 중증도 1~5, 요약, 방문 권고를 JSON으로 판단합니다.
3. **초안 작성** (`agent/drafter.py`): 간호사 확인이 필요하고 중증도 2~4인 건에 한해, 수간호사 말투와 few-shot 예시 2건(`agent/draft_examples.json`)으로 환자용 안내 초안과 간호사 전용 참고를 만듭니다. 약 복용·섭취 지시와 수치 해석은 금지하고, 일정 날짜는 모델이 아니라 코드가 채웁니다.
4. **검증** (`agent/guard.py`): 출력 형식을 검사하고, 증상이 있는 즉답은 간호사 확인으로 내리며, 환자에게 가는 접수 문구는 고정합니다.

환자에게 가는 의료 관련 문구는 모두 간호사 승인을 거칩니다.

## 실행
```
pip install -r requirements.txt
cp .env.example .env     # OPENAI_API_KEY 입력
python -m uvicorn main:app --port 8000
```
- 환자 화면: http://localhost:8000/patient.html (이름으로 로그인, 예: 박정호)
- 간호사 화면: http://localhost:8000/nurse.html (이름 입력, 비밀번호는 아무 값)
- 서버를 켤 때마다 대화 내역은 비워진 상태로 시작합니다.
- 환자 데이터(`data/patients.json`)는 가상 데이터입니다. 로그인은 화면 구분용이며 실제 인증이 아닙니다.
