# 검사별 준비 사항 (가상 병원)

| 검사 | 금식 | 준비 사항 |
|---|---|---|
| X-ray 검사 | 필요 없음 | 금속 장신구는 미리 빼 주세요. 검사실은 2층 영상의학과입니다. |
| 복부 초음파 검사 | 검사 8시간 전부터 금식 (물 포함) | 방광이 너무 비어 있지 않아도 됩니다. 검사실은 2층 영상의학과입니다. |
| 혈액 검사 | 보통 8시간 금식 | 아침 식사 전에 채혈합니다. |
| CT 검사 (조영제) | 4시간 금식 | 검사 전 조영제 동의서를 작성합니다. |
| 마취과 상담 | 필요 없음 | 복용 중인 약 목록을 준비하세요. |

- 검사 시간에는 간호사가 병실로 모시러 옵니다. 이동 전에 화장실을 다녀오세요.
- 검사 일정이 바뀌면 간호사가 알려 드립니다.
